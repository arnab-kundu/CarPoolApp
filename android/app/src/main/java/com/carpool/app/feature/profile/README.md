# Profile UI demo

Profile links to phone authentication, driver verification, vehicles, safety,
and privacy. Detail screens support toolbar and Android Back navigation.
Phone uses demo OTP 123456 (no SMS). Driver actions attach sample placeholders
and submit a mock pending application. Vehicles support add/edit with validation.
Safety has a sample editable emergency contact and preference toggles.
Privacy has local rating/product update switches and data visibility information.
Changes remain while navigating tabs, but reset on sign-out or activity recreation.
No real verification, documents, location, messaging, or external services are used.
