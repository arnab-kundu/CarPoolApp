# Demo chat

Inbox showcases three sample ride conversations, searchable by person or route.
Open a conversation to see ride context, dated incoming/outgoing message bubbles,
timestamps, and a composer. Opening a thread clears its unread badge.
Send appends a local message and scrolls to it; blank messages are disabled.
Toolbar and Android Back return to Inbox. Bottom navigation hides inside a thread.
History and sent messages remain while switching tabs, but reset on sign-out
or activity recreation. No backend messages or delivery receipts are sent.
